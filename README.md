# 🚛 Calculadora de Frete

Calculadora de pagamento por viagem para motoristas de carga, com suporte a múltiplas rotas, deduções configuráveis e exportação de relatório em Excel.

## Funcionalidades

- Seleção de rotas pré-definidas ou personalizada
- Cálculo automático de adiantamento, saldo bruto e líquido
- Deduções configuráveis: comissão, guarda, gerente, pneu/borracharia e outros
- Registro de abastecimento
- Exportação de relatório formatado em `.xlsx`

## Rodando localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Este app está hospedado no [Streamlit Community Cloud](https://streamlit.io/cloud).
